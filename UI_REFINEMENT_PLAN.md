# Islam Roots UI Refinement Plan

## Scope

This plan applies the pasted frontend/UI refinement requirements to the existing Islam Roots React application without rebuilding routes, data flows, authentication, AI, Google integrations, curriculum, students, lesson studio, memory map, or persistence.

## Verified visual reference

The supplied brand reference defines the core palette:

| Token | Value |
| --- | --- |
| Forest green / primary | `#1F6F4A` |
| Leaf green / secondary | `#2F8F5B` |
| Earth brown / root accent | `#8B5A2B` |
| Dark root brown | `#6B3F1D` |
| Soft ivory / moon | `#F3F0E6` |
| Warm sand / background | `#F7F3E9` |

The reference uses restrained pale-green surfaces, black/charcoal text and rules, and a warm neutral canvas. The product should use these as semantic tokens rather than scattering one-off values.

## Evidence-based priority order

1. Establish semantic CSS tokens, font stack, focus states, motion defaults, and Arabic direction/typography rules.
2. Refine the shared brand logo/header/sidebar so `ISLAM ROOTS` and `Workspace` are the stable hierarchy and `Teacher Edition` is removed from the primary shell.
3. Recompose the dashboard around Today, Students, Teaching Tasks, Progress, and AI Assistance using real data and useful empty states.
4. Reorganize Settings into intentional section cards with a responsive two-column layout and clear integration grouping.
5. Extend the Jalilah guide beyond Quran Memory Detective to cover global navigation, progress, settings, connections, exports, and library.
6. Remove normal UI italics and audit Arabic/RTL labels in the touched surfaces.
7. Validate at mobile, tablet, laptop, desktop, keyboard, dark mode, Arabic/RTL, build, and production deployment levels.
